# Duka Smart Electronics - Retail Sales Analytics

## Project Overview
This project analyzes sales, profitability, customer behavior, and growth trends for a fictional Kenyan electronics retailer using PostgreSQL.

## Objectives
- Identify top customers
- Analyze revenue and profitability
- Evaluate growth trends
- Segment customers by value
- Generate business recommendations

## Tools Used
- PostgreSQL
- Dbeaver
- GitHub

## Key Findings
- Mobile Phones generated the highest revenue (KSh 6.94M)
- Accessories delivered the highest profit margin (42.39%)
- Revenue peaked at KSh 2.24M in August 2026
- High-value customers account for a significant share of revenue
- Nairobi contains many of the top-spending customers

See ./insights.md for detailed business recommendations.
